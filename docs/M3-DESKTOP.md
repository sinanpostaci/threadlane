Bridge crate `crates/threadlane-desktop-bridge` is pure Rust, exported DesktopBridge::new(state_dir:Option<PathBuf>,demo_state_dir:Option<PathBuf>) -> Result<Self,BridgeError>; async snapshot(binding_id:Option<String>), attach(state_dir:String), run_detail(binding_id:String,run_id:String), start_demo(), answer_demo(expected_revision:u64), cancel_demo(expected_revision:u64); sync tool_status() -> Vec<ToolStatus>. Interior short-held mutex; no lock across network awaits except serialized demo mutation mutex. BridgeError Display safe. Tauri shell wraps methods, holds bridge State, maps errors safely.
CLI app --state-dir EXISTING_RUNTIME optional; --demo-state-dir OWNED_DEMO_RUNTIME optional. Default attaches demo dir if supplied, otherwise unconfigured. Never automatically create/write runtime state except explicit button using trusted demo client. Attach only changes observer, never demo identity. start_demo on dedicated demo runtime creates synthetic UUID binding Local demo and fixed demo instruction, remembers owned tuple; only this tuple may be answered/cancelled, compare revision before mutation. Demo button switches view to demo runtime; attach switches view to real observer. Deny replay/old demo controls. Fixed answer Continue. No arbitrary instruction/model/exe accepted from JS.
SupervisorClient::from_state_dir_lazy is sole live data boundary; never SQLite reads, never pull_events/ack_events (would consume Codex follower state). Per-call descriptor/token validation/restart recovery stays existing client. Enrich recent <=10 summaries via get_worker; ONLY WorkerNotFound falls back to get_run (core error); transport/security failure surfaces offline/blocked, never fake data. Missing effort/model evidence keeps Failed/ExecutionFailed. List binding cap100, do not fanout status to every binding. Scope selected binding existence. UI poll every2s without overlap; late attach/detail replies cannot overwrite newer selection. Closing GUI cannot stop attached external runtimes.
