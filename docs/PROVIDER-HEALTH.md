# Unverified provider diagnostic hints

Threadlane provides bounded AGY health observation and fixed native
diagnostic-availability callbacks. The evidence class is
`unverified_provider_diagnostic_hint`. Invocation-owned capture and exact
logger-like framing do not authenticate record semantics, prove provider
transport failure, establish root cause or exclude every log-text false positive.
An exact forged logger-shaped string can produce only unverified metadata.
Ordinary stdout, provider prose and tool output are outside this channel.

## Scope and authority

Original approved host Worker snapshots come through `ApprovedHostClient` and
must match binding/thread, approval subject, compiled task, sealed command,
actual run/worker/claim and active worker lifecycle. The current hint must already
exist in the durable original-host metadata. It remains separate from derived
attempts. The host is read again before native submission.

Planning requires the actual command ownership guard, Running command, immutable
command digest, matching grant/reservation/request/context/role and still-reserved
invocation. Reviewer, Closure and derived corrections require their actual
physical owner, active logical lease, frozen envelope and matching reserved
effect/subject/task/attempt/correlation. A durable current hint, currently
available/open diagnostic coverage and matching configured target are necessary
for a new callback. A separate typed live eligibility path leaves terminal
planning's no-active-owner rule intact.

No diagnostic hint changes a worker lifecycle, job failure, workflow hold,
acceptance, cancellation, deadline, dispatch or execution authority. Provider
results, immutable approvals, output overflow and Unknown receipt reconciliation
retain their original checks. A diagnostic is not productive-work evidence.

## Observation, delivery and current display

The worker health observer is a cumulative watch channel. Coalescing preserves
first/last observations, observed retry count and reported attempt high-water.
These are distinct from Threadlane attempts. Monotonic observation time does not
authenticate logger timestamps. Capture availability is independently
`available`, `unavailable` or `truncated`; missing/truncated coverage is not health.

Scoped supervision persists before scheduling a native notice. Native transport
runs outside the pipe reader, concurrently with polling the provider future.
Health uses its own stable invocation fingerprint, excluding owner reopen,
job revision, update sequence and internal retry count. Five retry observations
advance the counter but permit only one early health callback per invocation.

Both native notice stores deduplicate before quota checks. Health shares the
progress/failure attention subquota: new advisory attempts stop at 14 total
attempts, preserving two terminal/fatal slots within the existing total of 16.
Intent is durable before send. Submitted means backend acceptance only.
Interrupted intents and possible-send Unknown outcomes are never automatically
replayed. Optional persistence or delivery failures cannot replace a proven
supervised result. Owner release grants no new live health notice; the existing
verified terminal planning callback can still follow release.

Callbacks retain the existing fixed software-owned text asking for
`planning_command` or `execution_status`. No raw logs, diagnostic paths, prompts,
tool output, arbitrary errors or model overrides enter callbacks or durable health
metadata. Coworker reads the named scoped status once, without polling, and
explains AGY's unverified stream-idle/internal retry text, retry count/high-water,
elapsed time and availability in the human conversation language (Turkish in this
pilot). It must not infer client,
network or upstream root cause or treat the hint as permission to cancel,
redispatch, change models or extend timeout.

First/last observations remain history after recovery or terminal observation.
Native role source liveness additionally requires currently available/open diagnostic
coverage, alongside every existing owner, reservation/effect and lease fence.
SourceClosed, SourceLost, unavailable/unsupported and truncated coverage remains
bounded history; none can mint a new early notice intent/send or a live source
projection. Available coverage without a current hint may still be a live source;
a new notice additionally requires a current hint. Missing coverage is not healthy.

A watch-coalesced first hint whose source is already closed, lost or truncated can
remain history without a fresh early callback, even while enclosing invocation
cleanup holds a valid owner and unresolved reservation/effect. This is finite
coverage, not recovery, health or a guarantee of during-call delivery. Existing
hints, first/last observations and retry counters are retained, as are SourceLost
and ResourceLimit reasons when capture closes. Provider results and reconciliation
remain independent.

Scoped role views require `live` and `record.snapshot.current_failure` for current
advisory attention. Planning exposes these under `command.provider_health_views`;
the unprojected `command.provider_health` remains history. Planning recovery keeps
the immutable capture owner even when reconciliation claims a new command owner.
Original Worker early callbacks require the durable live-observation marker,
matching active host/worker lifecycle, and a diagnostic source that has not closed.
Workflow supersession fences new derived-role callbacks while retaining diagnostic
history and independent supervised results. Terminal status or owner loss
closes current advisory display, without erasing real failures, immutable
observations, counters or Unknown reconciliation requirements.

## Private finite capture

The supplied parent qualification for AGY 1.5.3 demonstrated opening a precreated
private 0600 log FIFO, redirecting diagnostic stdout/stderr there while keeping
stream-json results on the original stdout. The precreated private companion FIFO
was not opened in that isolated no-credentials/no-network startup. No unexpected
regular log file was observed. This is startup capture evidence supplied with
the task, not authenticated record semantics or live inference acceptance.

The parser retains at most a 16 KiB pending line, within the unchanged combined
1 MiB log/companion classification budget and finite record/snapshot limits.
The supplied target measurement was 66,817 bytes total, a maximum 4,173-byte
line and first retry offset 63,498. The previous 2 KiB bound stopped classification
before that retry; 16 KiB provides finite evidence-based headroom.

Legacy supervision calls explicitly pass no health observer and preserve their
existing argv, wire shape and bounded, secret-redacted stderr summary. Managed
Worker and role calls opt into health with an observer. For those AGY calls,
stderr summaries stay suppressed for the entire invocation, including capture
setup failure, unavailable sources and closed observers. Capture availability
and observer delivery never switch an invocation back to legacy diagnostics.

Sources remain private and bounded. Drains discard after classification exhaustion
without cancelling the provider. Source loss/rotation, incomplete closure and
resource exhaustion remain unavailable/truncated. There is no unlimited capture
or authenticated/all-pattern guarantee.
